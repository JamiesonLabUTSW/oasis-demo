# Start here: choose your path

Begin with the [three-note practice](../demos/synthetic-notes/README.md).
It works in a browser without an account, installation or model. Read the notes,
score the original criteria, then compare the authored answers. This is the
common introduction for every audience.

## Words used in the demo

| Term | Plain meaning |
| --- | --- |
| OASIS / MAPLES | The broader OASIS system and its assessment/review application. Your host supplies the supported application entry point. |
| Stack | The cooperating services started by a supplied installation kit. Healthy services alone do not prove grading works. |
| Image / manifest / kit | An image contains a service; a manifest pins exact image versions; the complete kit adds the compatible startup tools and configuration. |
| Encounter / group | One sample interaction or record, and the explicitly selected collection of encounters used for a task. |
| Rubric / criterion | The questions and score rules, and one individual question within them. |
| Note / Audio / Video / Transcript | Different input types. A transcript contains recognized or supplied text; it is not the same input as the original recording. |
| Transcription | Converting speech to text. Transcription does not produce rubric scores. |
| Grading run / result | A model task using specified inputs and a rubric, and the saved suggestions it produces. |
| Evidence / rationale | The supporting material cited for a suggestion, and its explanation. Review both against the source. |
| Pending / human review | A saved suggestion can remain Pending after the run finishes. Human review checks it; completion alone is not acceptance. |
| Export | A downloaded copy of saved results. Confirm an actual file arrived and that its contents match the selected run. |
| Local / cloud | Where a selected model processes a task. Local stack startup does not establish a fully local or offline model route. |

## From a sample to a reviewed result

On a rehearsed installation, your host supplies the exact named sample, rubric
and saved run. Open that selection rather than an unrestricted record list.
Check which input type was used, then inspect a criterion's score, evidence and
rationale. Compare the suggestion with the actual note, transcript or recording.
A saved-result tour does not require starting another model task.

Review changes are writes. A host may demonstrate them on a designated synthetic
practice result; participants should know whether the session permits edits or
is a read-only tour. A good discussion can identify a disagreement without
changing the saved record. Authored answers in this library are teaching examples,
not model results or a validated scoring standard.

For exports, open the downloaded file and check the run/sample, criterion count,
scores and review state. A success message alone is not a completed download.
The host must explain which export formats the supplied package has verified.

## Media and transcript demonstrations

A note-only example has no recording to play. For an audio/video example, first
confirm that the selected encounter has the intended media and that the host's
package supports the route. Check playback, seek/pause controls and the matching
transcript before discussing grading.

A source recording shown alongside transcript-based grading provides context.
Read the input/source label: seeing video does not establish that the model
received video. A recording from the same encounter is not automatically proof
of the exact historical input. The presenter should state the actual graded
input and any source-linkage limitation.

The [CDC conversation](../demos/cdc-conversation.md) is an external source reference.
This repository supplies no recording, transcript or companion rubric. Opening
that source supports discussion; it does not qualify an import, transcription or
grading route. Use a separately rehearsed and appropriately cleared route for
an application demonstration.

## Readiness has separate steps

1. **Content available:** the example and its provenance are readable.
2. **Artifacts accessible:** exact package/image bytes can be downloaded and checked.
3. **Installed on this machine:** prerequisites, sign-in, sample visibility and
   a retained stop/start have passed for this recipient.
4. **Task demonstrated:** the selected input/model route, review and reopened
   export passed within a recorded scope.

A PASS at one step does not establish the next. Current Apple Silicon image
publication and fresh-recipient acceptance remain separate from the already
published source/license companion; consult [current status](runtime.md).
