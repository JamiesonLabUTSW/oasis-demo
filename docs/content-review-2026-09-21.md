# General demo guide review — September 21, 2026

## Change and scope

The earlier participant guide directed every audience to one hosted trial and
assumed its seeded accounts, completed runs, provider choices and timings. This
revision makes the guide reusable for invited audiences: access details come
from the invitation, with clear note, transcript and audio/video paths.

Reviewed `hosted-guide.html`, `index.html`, `README.md`,
`docs/getting-started.md` and `docs/facilitator-guide.md`. The existing first-pass,
rubric-edit, rerun, human-review and export instructions remain. Added a separate
CDC transcript walkthrough and distinguished its new text criteria from the
media rubric. Model alternatives and AI authoring tools depend on the host's
configured access; no specific provider, model, response time or unlimited use
is promised for all audiences.

No source recording, transcript bytes, new rubric workbook, screenshots,
credentials, participant details or operator journals were added to this public
repository. Existing downloadable workbooks and demo notes are unchanged, as are
the license, notices and frozen image manifest. The CDC source notice remains.
The new instructions describe host-supplied material, not a new public download.

## Checks and limits

- Existing interface instructions derive from the selected application release
  `d40f19552eabaec60746922fe0e1c96cea7e1556`. The `Transcript Grading` model-control
  label and the built-in sign-in **Open User Guide** link were checked in that
  exact source. No application behavior is changed by this guide.
- The transcript workflow names its group, activity/case, five-item rubric,
  Transcript mode, station and 1–3 score scale explicitly. Host acceptance is
  required before advertising its availability.
- Public inventory/hash validation, local HTML targets and whitespace checks
  cover the revised public files. Browser review covers desktop/phone layout,
  exercise links and keyboard-operated disclosure controls.
- This review does not establish a general-demo deployment, accounts, model
  processing, live import, grading, saved review or export acceptance. Each
  operator must qualify the selected paths on the invited site.

## Review and publication

Prepared as a general-demo guide revision for owner review. Publishing the guide
does not provision access. The general-demo banner may link to the stable
`hosted-guide.html` URL after this revision is published. Dedicated deployments
retain their separately distributed invitation links and content arrangements.
