## Second pass, model choice and rubric template — September 19

sign in → prepared note → rubric → run → review → export, with step 4 opening
the completed starter run that every account now holds (or starting one if it
is absent). New Part 2 sequences the second pass: five ways to change the
rubric (Excel edit, `Enhance`, `Transform`, Wayfinder, `Create Rubric`), a
