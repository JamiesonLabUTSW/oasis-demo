# Notes review practice

**Original synthetic exercise · no installation or model required**

Three fictional notes describe a routine-planning conversation. Apply the same
criteria to each. This illustrates evidence-based review, not clinical assessment.

## Original practice rubric

Give one point when an item is explicitly present; zero when absent.
Do not infer facts from another note or this introduction.

| ID | Criterion | One point requires |
| --- | --- | --- |
| GOAL | Documents a goal | A stated wish to establish a morning routine |
| BARRIER | Documents a barrier | Forgetting the routine on busy mornings |
| PLAN | Documents a next step | Both a phone reminder and a paper checklist |

## Try it

1. Read [Note A](note-a.txt), [Note B](note-b.txt), and [Note C](note-c.txt).
2. Score the three items separately; quote supporting text or use “not found.”
3. Reveal the [illustrative answers](illustrative-answers.csv) after scoring.
4. Discuss disagreements. In a model-assisted workflow, a human reviews evidence
   and rationale before accepting or revising suggestions.

The start page includes these notes and expandable answers. Downloads work offline.
