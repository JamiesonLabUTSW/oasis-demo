An image pull is not a complete installation. Each recipient still needs sign-in, sample, and retained-restart checks. There is no general public installer here yet. Model weights, credentials, and restricted materials are not included. Runtime details.

  1. 1Get the matching package

    Ask your demo host for the kit, its checksum, prerequisites, and model/provider plan. Use its own instructions.

  2. 2Check, plan, install, verify

    Run the kit's commands in its specified terminal. Stop on a failed check and keep the error for support.

  3. 3Open your local sign-in helper

    The current Windows kit's guide command creates a local HTML page with Copy email and Copy password controls. Keep that page private on your computer.

  4. 4Rehearse a complete run

    Confirm sign-in, sample data, and a retained restart. Then run the kit's compatible synthetic sample, review the evidence, export, and reopen. Confirm local inference separately.

  5. 5Keep the guide handy

    Complete getting-started guide · Get help
