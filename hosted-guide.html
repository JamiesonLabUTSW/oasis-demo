Keep this guide open in a separate tab while using MAPLES. Your browser’s Print command also gives you a paper-friendly version.

1

Sign in to the shared demo

  1. Open the HTTPS demo link your facilitator provides.
  2. Enter your assigned Email and Password, then choose Sign In.
  3. Look for Groups, Rubrics and Grading in the MAPLES navigation.

The examples are shared across the session. Use your own assigned account for your groups, rubrics and runs. If a starter workspace is missing, ask the facilitator to finish preparing it.

Checkpoint: you are signed in as your assigned account and can open Groups and Rubrics.

Use the hosted link, not a localhost address from an older laptop guide. No private login-helper file needs to be downloaded or shared.

2

Choose one prepared note

A group is the set of encounters you want to assess together. If your host has prepared a starter group, use it for the first run and continue to the rubric.

Create your own group from the shared library
  1. Open Groups → Search Encounters. Leave Elephant origin at its deployment default.
  2. Use the host’s sample label in Activity or Case. Press Enter to add a filter, then select Search Encounters.
  3. Select one approved synthetic note encounter.
  4. In Enter group name, use a name you will recognize that includes your account label, then choose Create Group.

The default source may include the words “local stack.” In this hosted demo, that means the server’s prepared library.

Checkpoint: your group contains the intended note. You can identify its activity and case.

Encounter uploads are handled by the administrator. You can use the preloaded catalog without uploading files.

3

Understand the rubric first

A rubric defines the questions, evidence and score anchors used to assess the note. A station is a section of the rubric matched to a case.

  1. Open Rubrics and choose View on the prepared rubric named by your facilitator.
  2. Check its station, version and criteria. For this first exercise, use a Note rubric.
  3. Read the score anchors. Decide what evidence would justify each score before asking a model to assess it.
Checkpoint: you know which rubric version you will use and what its criteria ask for.

Use a prepared rubric for the first run. Creating a new one with Wayfinder is an optional second exercise.

4

Start one grading run

  1. Open Grading. Select your Group and Rubric; the rubric selector shows its version.
  2. Keep the host’s prepared model settings. For a note-only run, leave Localizer and Mosaic Videos off.
  3. If you see Station mapping required, choose Confirm Mapping. Match the activity/case to the rubric station your host identified, then confirm. Look for Mapping confirmed.
  4. Choose Start Grading once. Follow progress under Grading Runs.
  5. When it completes, choose View Results.
Checkpoint: one run completes and opens its results.

A queued run is still in progress. Use Refresh or Details to check it; repeatedly pressing Start Grading can create extra work. If it fails, share the run ID and error with the facilitator.

5

Read the evidence. Make the call.

Open an encounter in the results and select its Notes tab. Compare the original note with each AI assessment, its rationale and the rubric’s score anchors.

If you agree

Choose Accept AI for the item after checking its evidence and score.

If you would change it

Choose Review, select a permitted score in Run Scoring Guide, add optional Comments, and choose Save Review.

Reviewed Score is filled from the score anchor you select. A completed model run alone does not mean anyone has reviewed its results.

Checkpoint: the saved review reflects your judgment. Refresh and confirm it remains.
6

Export and open the workbook

  1. Choose Export Excel in the results view.
  2. If Export Incomplete Review? appears, choose Cancel to finish reviewing, or Export Anyway to download an incomplete review. Unreviewed rows have blank reviewed scores.
  3. Open the downloaded workbook and confirm the expected note, rubric items and review values are present.
Checkpoint: you have opened a real export and can explain one score using evidence from the note.

This is a temporary trial. Save the work you want to retain before the closing time your facilitator announces.

Next exercise · Edit, rerun, compare

Bring your own rubric and data

Upload and revise rubrics in your own account. For new data, your host adds the files to the shared encounter library. Start with a small fictional note and one clear change to a scoring criterion.

Edit a rubric in Excel

  1. Open Rubrics, find Trial documentation quality, and select Download. Keep a copy of the original workbook.
  2. Open the .xlsx file in Excel and edit a question or score description. Keep station sheet names and ItemKey values stable for a before-and-after comparison. Save as .xlsx.
  3. Return to Rubrics → Upload New Rubric. In the Upload Rubric dialog, choose New Rubric and give your experiment a distinct name. Check that Min Score matches the original scale. For this prepared rubric, keep it at 1 (the scores run from 1 to 3).
  4. Choose your edited workbook, complete the upload, and open View to check the criteria, score anchors and version.
  5. In Grading, select the same sample group and your edited rubric. Confirm the station mapping, then start one run.
Update a rubric you already uploaded

Choose Upload New Rubric → Replace Existing, select your rubric, choose the edited workbook and confirm. MAPLES creates the next version under that rubric name. Earlier runs remain associated with their original version. Check the version selected in Grading before rerunning.

Workbook format and score scale

Use one sheet per station. Keep these exact column names: ItemKey, Mode, Section, QuestionText, Response1, Response2. Add Response3 and later levels in order if needed. Each item needs at least two nonblank response descriptions with no gaps.

Use Note for the first exercise. Each ItemKey must be unique within its station. Min Score sets the score for Response1; the next response receives the next integer. For a 0/1 rubric, set Min Score to 0. Do not add “N/A” placeholder score levels.

The app’s User Guide → Rubric Format Guide describes optional columns and other modalities. This upload accepts Excel .xlsx files. Wayfinder-generated YAML uses the Wayfinder upload handoff.

Add a new note with your host

  1. Prepare one small .txt file with original fictional content. You can also use a public practice note from this site.
  2. Give the file to the facilitator through the session’s agreed channel, along with a short Activity label and Case label. Say which rubric station should assess it.
  3. The host uploads the note and returns the exact Activity/Case labels. The encounter becomes part of the shared demo library, so use material suitable for everyone in the session.
  4. Open Groups → Search Encounters, filter by those labels, select the new encounter and create a group. Continue with your rubric and station mapping.

Participant accounts do not show the administrator’s upload form. That is expected. Keep real patient or learner records and institutional workshop packets out of this public/synthetic trial.

Facilitator: upload a small note
  1. Sign in with the host’s administrator account and open Encounters → Upload encounter.
  2. Complete Learner full name, Learner email, Cohort, Activity, Case, Date and Time. Use fictional demo identifiers.
  3. Choose the nonempty text file and explicitly select Notes (.txt) as its type; text files can also be transcripts.
  4. Choose Submit encounter. Confirm the upload and use Use this encounter in a group, or give participants the Activity/Case labels to find it in their own accounts.

Start with a small note. The hosted demo currently limits the whole upload request to 16 MB, even if the application displays a larger file allowance. Arrange larger media with the operator before the session.

Compare one change: score the note yourself first, inspect the initial AI result, edit one rubric criterion, and rerun the same note. Keep both exports with their rubric versions. Compare the AI scores and human-reviewed scores separately.

If using an external comparison tool, first check one actual MAPLES export with the facilitator. Match item/case IDs, rubric versions and score scales; workbook compatibility has not yet been verified.

Optional · After your first run

Make a small rubric with Wayfinder

Wayfinder helps draft a rubric. Start with a short note-only task and inspect the result before grading. Send one request at a time and let it finish before sending another.

Try a conversation

  1. Open Wayfinder and describe the rubric you want. Ask for a draft first.
  2. Review and refine the criteria and score anchors.
  3. When satisfied, explicitly ask Wayfinder to upload the rubric. Confirm Rubric upload succeeded., then find and View it under Rubrics.

Draft a note-only rubric for a fictional planning conversation. Check whether the note states a goal, describes a barrier, and records a specific next step. Use clear 0/1 anchors. Show me the draft before uploading it.

This is an original instructional prompt, not a validated assessment instrument.

Use the Create Rubric form instead

Open Rubrics → Create Rubric. Optionally enter a Name, select Note under Modalities, describe the criteria in Details, then select Submit.

Submit generates and uploads the rubric. It is not only a preview. Reopen its View page before using it.

If a request times out, refresh Rubrics and look for the new item before trying again. A late upload may have succeeded. Chat history can clear on refresh; an uploaded rubric is saved separately.

If Wayfinder is unavailable, continue with the prepared rubric. It is not needed to complete the first walkthrough.

If something gets in the way

Keep your place. Ask for help.

I cannot sign in, or I do not have an account

Use the latest hosted URL and the account assigned to you. Check copied spaces and capitalization in the password. There is no public registration. Ask your facilitator for access or a reset; do not post credentials in an issue or chat.

I do not see any sample encounters or a starter rubric

Check Groups → Search Encounters, leave the deployment default selected, and clear unexpected filters. Ask the facilitator which activity/case and rubric are ready. Do not substitute personal records or upload another participant’s files.

The run is queued, slow or failed

Check Grading Runs and Details. Other participants share the hosted service and model capacity. Avoid starting duplicates. Give the facilitator the run ID, the action you took and a sanitized error message; do not include passwords, keys or signed file links.

A Wayfinder request timed out

Check the refreshed rubric inventory for a completed upload before resubmitting. If the interface asks you to acknowledge the inventory, use “I reviewed this refreshed inventory — allow another request” only after checking it. The prepared rubric remains available for the main walkthrough.

The page refreshed—did I lose my work?

Check your groups, uploaded rubrics and existing runs before recreating anything. Saved reviews should remain; unsubmitted edits and Wayfinder chat history may not. Refresh the run and inspect its state before trying another request.

Can I upload my own rubric or note?

Yes: follow Upload rubrics & data. Upload a compatible Excel rubric in your own account. Give new fictional demo notes to the facilitator for the shared library. Media needs a host check first.

Can I install this on my laptop?

Follow the assisted setup guide. You can complete this hosted session with your browser; no local installation is required.
